# 卡拉彼丘关系提取

逐页审阅全部来源后填写关系工件。每条关系包含对象、类型、归纳摘要、对目标角色行为的影响、状态、事实或推断标记、来源 ID，以及能在原文定位的 `evidence` 摘录。

关系摘要使用自己的话，回答“双方如何相处、这段关系如何影响目标角色的判断或表达”。不得仅因同阵营推定关系，也不得把缺少互动证据的角色写入。

单卡校验运行 `node scripts/run.js '@relationships.json'`；全部角色完成后运行 `node scripts/run.js aggregate '@request.json'` 生成双向关系总表。
