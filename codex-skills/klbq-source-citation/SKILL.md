# 卡拉彼丘声明证据校验

运行 `node scripts/run.js '@input.json'`。每条非未知声明必须同时提供 `citations` 与 `evidence`；每项 evidence 包含来源 ID 和连续原文摘录。

覆盖率只统计能够在对应来源全文中定位的证据，不再把“来源 ID 存在”视为已覆盖。输出报告保留声明、证据和来源索引，但不复制完整来源正文。
