# 卡拉彼丘人物综合分析

运行 `node scripts/run.js prepare '@related.json'` 建立分析工件，阅读其中全部 `sources[].content` 后人工填写，再运行 `node scripts/run.js validate '@analysis.json'`。

不得按固定前缀、固定字符数或单一标题截取资料。逐页审阅所有来源，在 `source_review` 中记录用途或排除原因；页面范围不限制，结论由跨来源综合决定。

每条声明使用自己的话归纳，并填写 `text`、`basis`、`citations` 和 `evidence`。`evidence` 必须是可在对应来源全文中定位的连续原文摘录，只留在 JSON，不复制到角色卡正文。无法从现有资料确认的反应使用 `basis: unknown`，不要补写。

`background` 形成当前身份、至少两项关键经历、当前目标及未解线索的因果链。`soul` 覆盖核心动机、观察优先级、决策规则、压力反应、信任模式、弱点和明确未知项，并据此写成自然的第三人称总结。

禁止把任务条件、礼物表、技能数值、媒体文件名、导航、版本记录或来源说明写进总结。禁止为凑长度重复句子。除示例台词与内部 evidence 外，连续照抄来源 80 字即校验失败。
