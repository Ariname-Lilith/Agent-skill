# 卡拉彼丘角色卡编译

运行 `node scripts/run.js '@input.json'`。输入必须先通过人物、外貌、台词、引用与关系校验；编译器只排版，不生成或补齐内容。

- 基础身份：姓名、性别、阵营、生日、星座、年龄、身高、体重、住址、兴趣爱好、饮食习惯。
- 外貌：发型与发色、眼睛、面部特征、体型与身高观感、服装、饰品与辨识特征、整体气质。
- 背景概述：用自己的话综合身份、关键经历、当前目标与未解线索。
- 角色灵魂：用第三人称呈现动机、观察方式、决策、压力、信任、弱点与未知边界。
- 语言风格、称谓规则和 3 至 4 条跨场景真实台词置于角色灵魂下。
- `relationships` 有内容时输出第五部分初始人际关系。

默认字符范围 1200 至 2400，允许上限最高 2600；不得用重复句或页面原文凑长度。
