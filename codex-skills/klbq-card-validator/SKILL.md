# 卡拉彼丘角色卡验收

运行 `node scripts/run.js '@validator.json'`。验收不仅检查格式和字符数，还要求：

- 综合人物分析报告已逐页审阅全部来源并通过声明证据定位。
- 背景与角色灵魂没有任务、礼物、技能、媒体、导航或生成过程元话语。
- 角色灵魂覆盖动机、决策、压力、信任、弱点和未知边界，且没有重复长句。
- 内部原句至少六条、四类场景，并选三至四条作为语言风格锚点；卡面另有三至四条基于人物模型新写的多场景台词，每条回指风格锚点，且不得使用游戏界面触发标签。
- 引用报告的声明证据定位率为 100%。
- 默认要求至少一条已验证初始关系；仅在明确设置 `require_relationships=false` 时省略第五部分。
- 默认字符范围 1200 至 2400，硬上限 2600。
